# REST API Documentation

Base URL for local execution: `http://localhost:8080`

All write requests use `Content-Type: application/json`. IDs are generated by PostgreSQL.

## Health check

`GET /api/health`

Confirms the application can query the configured PostgreSQL database.

## Farmers

- `GET /api/farmers`
- `GET /api/farmers/{id}`
- `POST /api/farmers`
- `PUT /api/farmers/{id}`
- `DELETE /api/farmers/{id}`

Example body:
```json
{
  "farmerName": "Sample Farmer",
  "phone": "9000000000",
  "village": "Sample Village",
  "district": "Erode"
}
```
`farmerName` is required. A farmer with linked fields cannot be deleted until those links are removed or reassigned.

## Fields

- `GET /api/fields`
- `GET /api/fields/{id}`
- `POST /api/fields`
- `PUT /api/fields/{id}`
- `DELETE /api/fields/{id}`

Example body:
```json
{
  "farmerId": 1,
  "fieldName": "North Field",
  "areaAcres": 1.5
}
```
Farmer ID, field name and positive area are required.

## Crops

- `GET /api/crops`
- `GET /api/crops/{id}`
- `POST /api/crops`
- `PUT /api/crops/{id}`
- `DELETE /api/crops/{id}`

Example body:
```json
{
  "cropName": "Rice",
  "cropType": "Food Crop"
}
```
Crop name and crop type are required. A crop referenced by a yield record cannot be deleted.

## Seasons

- `GET /api/seasons`
- `GET /api/seasons/{id}`
- `POST /api/seasons`
- `PUT /api/seasons/{id}`
- `DELETE /api/seasons/{id}`

Example body:
```json
{
  "seasonName": "Kharif",
  "startDate": "2026-06-01",
  "endDate": "2026-10-31"
}
```
Dates use ISO format (`YYYY-MM-DD`); end date must not be before start date.

## Yield records

- `GET /api/yield-records`
- `GET /api/yield-records/{id}`
- `POST /api/yield-records`
- `PUT /api/yield-records/{id}`
- `DELETE /api/yield-records/{id}`

Example body:
```json
{
  "fieldId": 1,
  "cropId": 1,
  "seasonId": 1,
  "yieldKg": 2500
}
```
All foreign-key IDs and a non-negative yield are required.

## HTTP status expectations

| Status | Meaning |
|---|---|
| 200 | Successful read, update or delete |
| 201 | Record created |
| 400 | Invalid input |
| 404 | Requested record does not exist |
| 409 | Delete blocked by a linked record |
| 5xx | Unexpected server or database error |

The exact error response body is produced by Spring Boot. Use the returned message for troubleshooting.
