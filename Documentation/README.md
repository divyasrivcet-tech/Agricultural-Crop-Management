## Original course documents

The original DOCX course documents are retained in `Course_Documents/`. The extracted evidence images are retained under `Evidence/DBMS`, `Evidence/Java`, `Evidence/Software_Engineering` and `Evidence/FDS`.

## Evidence policy

Images extracted from the supplied course documents are not presented as proof of a fresh run of the current source code. Capture new application, database, build and Python screenshots in `Evidence/Project_Run/` after executing the project. Test cases are marked pending until actually run.

## Submission checklist

1. Replace student/institution placeholders in the reports.
2. Review the schema and back up any existing database before migration.
3. Run the application and capture genuine screenshots.
4. Execute the API smoke test against a development database.
5. Update the testing report with actual outcomes.
